# Generated report examples

These two four-page PDFs are API-key-free demo artifacts generated with the supplied LTTS and POCL Q2FY26 public documents as validation inputs.

They use the application’s `DEMO_MODE`, which is included so reviewers can run the full report workflow without providing an API key. Their fixture data mirrors disclosed quarterly figures and source references; it is not presented as a live Claude extraction. To generate live, evidence-reconciled LTTS and POCL outputs, add a key to `.env.local` and run `pnpm examples:live`.
